# GitHub 가드레일

- `main`은 안정 기준 브랜치이며 직접 푸시하지 않는다.
- `dev`는 통합 브랜치다. 기능 작업은 `feat/*`, 수정은 `fix/*` 브랜치에서 진행한다.
- 커밋 전에는 의도한 파일만 `git status`로 확인하고 테스트 결과를 검토한다.
- `.env`, API 키, 서명키, keystore, APK/AAB, 원문 SMS, 실제 카드 끝 4자리, 개인 영수증은 커밋하지 않는다.
- 공개 저장소에 올리는 테스트 데이터는 반드시 마스킹한다.
- 커밋 작성자 이름·이메일은 사용자 설정을 사용하며 자동화 도구 이름을 작성자로 사용하지 않는다.
