# Google Play Console 제출 자료

## 앱 기본 정보

- 앱 이름: `신청해 계산기`
- 기본 언어: 한국어(대한민국)
- 앱/게임: 앱
- 무료/유료: 무료
- 카테고리: 금융
- 패키지 ID: `io.github.cjsan30.shinhanhae.calculator`
- 버전: `1.2` (`versionCode 3`)
- 최소 Android: Android 10(API 29)
- 대상 Android: Android 16(API 36)

## 스토어 설명

### 짧은 설명

신청해 지원금의 계획, 결제 내역, 잔액과 증빙을 한곳에서 관리합니다

### 전체 설명

신청해 계산기는 지원금 사용 계획과 실제 지출을 기기 안에서 관리하는 Android 앱입니다.

주요 기능

- 정주비와 학습공간비의 계획 금액, 사용액, 잔액 확인
- 삼성 메시지·신한 SOL의 신한카드 승인 알림 자동 인식
- 처음 보는 결제처는 미정 지출로 보관한 뒤 직접 분류
- 상호명 키워드 기반 자동 분류 규칙
- 예산 사용률 1차·2차 경고와 초과 알림
- 신한카드 엑셀 거래내역 가져오기
- 직접 지출 등록과 결제 내역 수정·취소·삭제
- 홈 화면 위젯에서 잔액과 사용률 확인
- 영수증 이미지를 순서대로 합친 증빙 PDF 생성
- 암호화 백업과 복원

개인정보와 데이터

자동 인식은 사용자가 허용한 삼성 메시지·신한 SOL 알림 중 등록한 카드와 일치하는 신한카드 승인 알림만 기기 안에서 처리합니다. 같은 승인이 두 앱에 표시되면 한 건으로 합칩니다. 원문 알림과 다른 대화는 저장하거나 외부로 전송하지 않습니다. 거래·정책·분류 규칙은 기기 내부 암호화 저장소에 보관합니다. 알림 접근을 사용하지 않는 경우에도 신한카드 엑셀 가져오기와 직접 등록을 사용할 수 있습니다.

지원 범위

- Samsung Messages를 사용하는 Android 기기
- 신한카드 체크 승인 알림
- 자동 인식이 중단된 기간은 카드 엑셀 또는 직접 등록으로 보완

## 앱 콘텐츠 권장 답변

### 앱 액세스

- 계정 로그인: 없음
- 검토자는 최초 화면에서 임의의 카드 끝 4자리 입력 후 알림 접근을 허용하고 계획표를 직접 입력해 전체 기능을 확인할 수 있음
- 실제 카드 거래 없이 직접 지출 등록과 거래내역 화면 검토 가능

### 광고·대상 연령

- 광고 포함: 아니요
- 대상 연령: 만 18세 이상
- 뉴스 앱: 아니요
- 건강 앱: 아니요
- 정부 앱: 아니요

### 금융 기능

- 예산 및 지출 관리 기능
- 송금, 대출, 투자, 암호화폐, 보험, 금융상품 판매 기능 없음
- 실제 결제 실행이나 금융기관 계정 로그인을 수행하지 않음

## Data safety 초안

현재 릴리스 코드 기준으로 앱은 사용자 데이터를 서버나 제3자에게 전송하지 않는다.

- 데이터 수집: 없음
- 데이터 공유: 없음
- 전송 중 암호화: 해당 없음(외부 전송 없음)
- 기기 내 저장: 암호화 SQLite 및 Android Keystore 기반 저장
- 계정 생성: 없음
- 삭제: 개별 거래 삭제, 앱 데이터 초기화 또는 앱 제거

Play Console 답변은 최종 AAB에 포함된 SDK와 실제 네트워크 동작을 다시 대조한 뒤 확정한다.

## 그래픽 자산

- Play 아이콘: 512×512 PNG, 1MB 이하
- 기능 그래픽: 1024×500 PNG 또는 JPEG, 알파 없음
- 휴대전화 스크린샷: 최소 2장, 각 변 320~3840px, 긴 변은 짧은 변의 2배 이하
- 스크린샷에서는 실제 카드 끝자리·거래 원문·개인 알림·통신사 정보를 노출하지 않는다.

## 배포 순서

1. `build-play-release.ps1`로 서명 AAB를 만든다.
2. Play Console에서 앱을 생성하고 Play App Signing을 사용한다.
3. 개인정보처리방침 URL과 앱 콘텐츠 설문을 완료한다.
4. 메인 스토어 등록정보와 그래픽 자산을 입력한다.
5. 내부 테스트에 AAB를 업로드해 설치를 확인한다.
6. 새 개인 계정이면 12명 이상 비공개 테스트를 14일 연속 유지한 뒤 프로덕션 액세스를 신청한다.
