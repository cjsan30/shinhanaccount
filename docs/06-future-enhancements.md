# 후속 개선 계획

이 문서는 현재 출시 범위에서 의도적으로 보류한 기능을 기록한다. 보류 항목은 현재 기능의 완료 기준이나 배포를 막지 않는다.

## P0 — Android 홈 위젯

- 목적: 앱을 열지 않고 총 잔액, 정주비 잔액, 학습공간비 잔액, 미정 지출 건수를 확인한다.
- 표시: 금액 표시형과 금액 숨김형을 제공한다.
- 갱신: 승인 알림·수동 등록·분류 변경·취소·정책 변경·복원 직후 앱 데이터와 같은 값으로 갱신한다.
- 검증: S25 Ultra / Android 16에서 위젯과 앱의 잔액·미정 건수가 일치하는지 확인한다.

## P1 — 취소 알림 자동 매칭

- 현재 상태: 사용자가 최근 결제에서 직접 취소를 확정할 수 있다.
- 착수 조건: 개인정보를 가린 삼성 메시지의 신한카드 취소 알림 샘플을 확보한다.
- 처리 기준: 카드 끝 4자리, 금액, 정규화 상호명, 거래 시각, 승인번호(있을 때)를 비교한다.
- 안전 기준: 후보가 없거나 여러 건이면 자동 차감하지 않고 `취소 확인 필요`에 보관한다.
- 검증: 정상 취소·부분 취소·복수 후보·매칭 실패 사례를 실제 기기에서 점검한다.

## P1 — 대량 증빙 PDF의 백그라운드 처리

- 현재 상태: PDF는 앱을 연 상태에서 진행률을 표시하며 생성한다.
- 보류 이유: 한 달치 이미지는 많을 수 있으나, 지금은 처리 과정과 실패 원인을 사용자에게 즉시 보이는 편이 안전하다.
- 향후 방향: Android WorkManager 기반의 네이티브 작업으로 이미지를 순차 압축·PDF 생성한다. 앱이 보일 때는 화면 안 진행도를, 백그라운드 전환 시에는 취소 가능한 고정 알림의 진행도를 보여 주고 완료 시 결과 알림을 보낸다.
- 완료 기준: 앱을 닫거나 화면을 전환해도 작업이 유지되고, 완료 파일을 `Downloads/신청해 계산기`에서 확인할 수 있다.

## P1 — 설정 정보 구조 정리

- `카드 및 권한`, `정책`, `거래 가져오기`, `백업 및 복원`을 독립된 설정 항목으로 분리한다.
- 앱 정보에는 카드 끝 4자리 마스킹 상태와 삼성 메시지 알림 접근 상태를 표시한다.
- 개발 테스트 기능은 출시용 화면에서 숨기고, 내부 테스트 빌드의 별도 개발 메뉴에만 둔다.

## P2 — 동기화와 확장

- 다중 기기 동기화: 암호화된 사용자 백업 또는 사용자 선택형 클라우드 백업을 검토한다.
- iOS 지원: iOS의 메시지 접근 제약을 고려해 파일 가져오기와 수동 등록을 중심으로 별도 설계한다.
- 스토어 배포: 개인정보 고지·Data safety·release 서명·오류 보고 절차를 검토해 진행한다. Android 빌드에는 SMS 권한을 포함하지 않는다.

## P2 — 범용 지원금 관리 앱으로 일반화

- 방향: 현재의 신청해 특화 정책·용어·제출 흐름을 유지하면서, 다른 교육·훈련·복지·청년 지원금 사업에도 적용할 수 있는 선택형 구조로 확장한다.
- 사업 템플릿: 사업명, 지원 기간, 예산 그룹, 세부 항목, 항목별 한도, 경고 기준, 인정 증빙 규칙을 하나의 템플릿으로 정의하고 사용자별로 적용한다.
- 용어 분리: `정주비`, `학습공간비`, `신청해` 같은 표시 문구는 데이터 모델의 고정값이 아니라 템플릿별 표시 이름으로 관리한다.
- 거래·증빙: 카드 알림 인식, 파일 가져오기, 직접 등록, 증빙 PDF 생성은 공통 기능으로 유지한다. 카드사·은행·제출 서식별 파서는 템플릿 또는 연동 모듈로 분리한다.
- 보고서: 사업별 사용 보고서 양식, 제출 기간, 파일 용량 제한, 항목별 집계 기준을 설정값으로 둔다.
- 전환 기준: 신청해 버전의 실사용 안정성, 취소 처리, 비공개 테스트 및 Play 출시 흐름이 안정된 뒤 별도 제품 기획으로 착수한다. 기존 신청해 사용자 데이터와 정책은 변경하지 않는다.

## P2 — 초장형 영수증 PDF 가독성

- 현재는 사진 전체를 비율 유지해 한 페이지 안에 넣으므로 일반 카메라 사진도 잘리지 않는다.
- 세로가 매우 긴 영수증은 한 페이지에서 글자가 작아질 수 있다. 실제 제출 검증에서 식별이 어렵다면 겹침 여백을 둔 다중 페이지 분할을 추가한다.
- 자동 가장자리 자르기는 영수증 훼손 위험이 있어 기본 기능으로 사용하지 않는다.
