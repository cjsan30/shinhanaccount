# 실기기 확인 체크리스트

자동·단위·통합·보안 테스트와 별도로, 아래 항목은 실제 기기 화면 또는 실제 파일·알림을 사람이 확인해야 한다. 이 목록은 구현 완성도 점수에 포함하지 않는다.

## 거래내역 등록

- [ ] 카드번호를 선택했을 때 카드 CSV·Excel 안내와 `신한카드 앱 열기`가 보인다.
- [ ] 계좌번호를 선택했을 때 은행 PDF 안내와 비밀번호 입력칸이 보인다.
- [ ] 카드 CSV와 보호된 은행 PDF를 각각 실제 파일로 읽고, 끝 4자리 불일치·미확인 경고가 의도대로 보인다. 비밀번호 없이 보호 PDF를 읽으면 “암호화된 PDF입니다. 비밀번호를 입력한 뒤 다시 읽어 주세요.”가 보인다.
- [ ] 파일 읽기 결과에 `파일에서 읽은 / 정책 기간 내 / 기간 외 제외 / 입금 제외` 건수가 자동으로 표시된다.
- [ ] 8월 17일~9월 30일 은행 PDF에서 9월 15일·16일을 포함해 정책 기간(매월 15일~익월 10일) 안의 출금 31건만 추가되고, 입금·기간 외 출금은 저장되지 않는다. 상세 목록은 최신순으로 보인다.

## 영수증·제출서류

- [ ] 서로 다른 형태의 영수증 3장 이상에서 OCR이 날짜·금액을 읽고, 날짜+금액이 하나뿐인 결제는 자동 연결된다. 읽기 실패 시 사유와 `영수증 다시 읽기`가 보인다.
- [ ] 같은 날짜·금액 결제가 둘 이상이면 자동 연결하지 않고 사용자가 직접 선택할 수 있다.
- [ ] OCR을 읽지 못한 영수증도 날짜·금액·결제처 입력과 직접 선택으로 연결할 수 있다.
- [ ] 긴 세로 영수증은 비율을 유지한 채 한 PDF 페이지에 한 장만 들어간다.
- [ ] 생성 PDF의 입출금내역은 원본 PDF의 페이지·표 배치를 유지한다. 계좌번호와 입금·기간 외·사업 무관 행은 모자이크 처리되고, 정책 기간 내 출금 행은 원본 그대로 읽을 수 있다. 보호 PDF는 생성 시 비밀번호를 다시 입력하며, 비밀번호는 저장되지 않는다.
- [ ] `미리보기`를 누르면 기기에 설치된 PDF 앱 선택 화면 또는 PDF 앱이 열린다.
- [ ] 기본 제출서류, 세 가지 압축 품질 비교 PDF 모두 5MB 이하이며 PC·휴대폰에서 텍스트와 영수증을 읽을 수 있다.

## 화면·데이터

- [ ] 미정 지출에서 `바로 분류`와 `사업 무관 제외` 버튼은 같은 높이·폭으로 보이며 작은 화면에서도 글자가 잘리지 않는다.
- [ ] 데이터 초기화 선택 카드의 체크 영역과 설명이 함께 눌리고, 선택하지 않은 데이터는 유지된다.
- [ ] 계획표에 한 줄로 `식비 200000원 교육비 160000원 교통비 140000원 카페 200000원`을 입력해 읽고 확정한 뒤 앱을 재시작해도 정주비·학습공간비 모두 유지된다.
- [ ] 앱 재실행 후 영수증 연결·분류·정책·가져오기 결과가 유지된다.
