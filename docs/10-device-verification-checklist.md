### 검증 중 발견한 안내 개선점

- 미정 지출 상단의 가져오기 요약은 가져온 직후의 집계다. Yes/No를 모두 처리해도 ‘중복 확인 필요 4건’이 남아 실제 남은 확인 건수처럼 보일 수 있었다. **1.3.6 / code 10에서 수정:** ‘가져오기 당시 집계 · 중복 후보’와 ‘현재 중복 확인 필요’를 분리했다. 현재 건수는 실제 미정 거래를 기준으로 Yes/No 직후 갱신하며, 복수 후보도 거래 한 건으로 집계한다. 단위·컴포넌트 및 앱 통합 회귀로 확인했다. 해당 안내 변경의 실기기 시각 검수는 이번 릴리스 생성 작업에서 추가로 실행하지 않았다.
- KFC 원본 사진의 하단 잘림은 앱 출력 과정의 손실이 아니다. 잘린 사진을 추가한 뒤 PDF에서 복원할 수는 없으므로 원본 전체가 들어오도록 재촬영하는 것이 필요하다.

이번 실행은 검증이며 앱 기능·versionCode·APK를 변경하지 않았다. 관련 단위 회귀 3개 파일 16개 테스트도 다시 통과했다. 기존 구현 완성도 95%와 이번 실기기 판정은 별도로 유지한다.

### 데이터 보존과 증거

- 원본 암호화 DB 사본으로 복원했고, 결제·정책·분류 규칙·보고서 첨부·연결 상태 및 증빙 파일의 해시가 검증 전과 같다. 사용자 백업은 수정하지 않았다.
- 시험 영수증만 제거했다. 원본 증빙은 삭제하지 않았으며 생성한 품질 PDF 3개는 휴대폰 Downloads에 남겨 두었다.
- 승인받은 생성 PDF·렌더링·집계 증거는 로컬 `audit/current-device-audit/`에 보관한다. 금융 PDF·이미지·DB 사본은 Git에 포함하지 않는다. 거래 원문 JSON과 원본 영수증 화면은 PC로 내보내지 않았다.
- KFC 원본 확대 미리보기 화면의 추가 저장·대조는 사용자 요청으로 생략했다. 해당 판단은 이미 수집한 기기 내부 압축 해시와 승인된 생성 PDF에 한정한다.
