# 실기기 확인 체크리스트

기준: 2026-10-07 내부 디버그 빌드. 아래 사람의 실기기·파일 확인은 구현 완성도에 포함하지 않는다. 자동 테스트 통과는 실제 알림 수신, 이미지 인식 정확도 또는 출력물 가독성을 보증하지 않는다.

## 이번 수정 후 확인

- [ ] 고대비 모드에서 계획표·파일 읽기·PDF 생성 등 흰 버튼 글자가 검정으로 읽힌다.
- [ ] 작은 화면과 OS 최대 글자 크기에서 제목·빠른 확인·분류 버튼·PDF 창·도움말이 잘리지 않고 모든 버튼에 접근할 수 있다.
- [ ] 측정 시작은 0%로 표시되고, 영수증은 ‘장’, 측정 반복은 ‘회’로 구분된다.
- [ ] 과거/현재 측정 중 ‘생성 취소’를 누르면 멈추고, 첨부 파일은 남으며 미완료 측정 결과와 파일은 생성되지 않는다.
- [ ] 같은 영수증·순서로만 과거/현재 결과가 비교된다. 파일 추가·삭제·순서 변경 시 이전 결과가 사라지고, 더 느림·같음도 사실대로 표시된다.
- [ ] 설정 → 데이터 관리 → 계획표 → ‘저장된 계획·기간 수정’에서 기본 15일~익월 10일과 사용자 기간을 확인한다. 변경·확정·완전 종료·재실행 후 기간과 금액이 유지되고 가져오기·예산·영수증 후보·제출 PDF가 같은 기간을 사용한다.
- [ ] 날짜를 직접 선택하면 OCR 성공이라고 안내하지 않고 해당 날짜의 결제만 나온다. 결제를 한 번 탭하면 연결되고, 이미 연결된 결제는 다른 후보에서 제외된다.
- [ ] 영수증 연결이 없어도 경고 후 PDF 생성이 가능하다. ‘증빙 준비’ 자동 확인도 미연결만으로 실패하지 않는다. 읽지 못한 입출금 PDF는 준비 완료로 처리하지 않는다.
- [ ] PDF 도움말의 ‘결제 연결’ 단계가 실제 결제 후보 또는 날짜 입력 위치를 가리킨다. 다음·이전·닫기가 자연스럽다.
- [ ] 미정 지출 카드 사이 간격이 일정하다. 카드 CSV·Excel / 은행 PDF 안내와 선택 파일 형식이 일치한다.
- [ ] 검증 결과 내보내기에 실제 버전·빌드·플랫폼이 표시된다.
- [ ] 카드·알림 접근을 설정하지 않은 초기 상태에서 앱을 완전 종료해도 복구 경고가 뜨지 않는다. 초기 설정을 건너뛴 안내와 계획표 항목 설명이 이해하기 쉽다.

## PDF 품질과 성능 — 목적을 분리해 확인

- [ ] 짧은·일반·긴 영수증 최소 3장으로 ‘압축 품질 비교 생성’을 실행한다. default / compact / minimum 3개 파일이 열리고 각각 정확한 바이트 용량이 표시되며 5MB 이하인지 확인한다.
- [ ] compact와 minimum의 **모든 페이지**를 확대한다. 원본과 비교해 날짜·금액·상호명·영수증 글자가 읽히고 잘림·다른 행을 침범하는 마스킹이 없는지 확인한다. 이는 시간 비교가 아닌 **가독성·배치 검수**다.
- [ ] 영수증 20장 이상을 같은 순서로 넣고 과거 방식 1회, 현재 방식 3회 측정한다. 현재 방식은 중앙값이다. 동일 입력·기기에서 시간과 파일 크기를 함께 비교한다.
- [ ] 일반 PDF 생성 후 요약·원본 입출금 이미지·회색 제외 영역·미연결 영수증 별도 묶음·긴 영수증 한 장당 한 페이지를 확인한다. ‘미리보기’로 외부 PDF 앱에서 열린다.

## 초기화와 실제 카드 Excel — 무엇을 검증하는가

- [ ] 초기화 3개 범위(결제/미정 지출, 분류 규칙, 정책)의 **선택 가능한 7가지 조합**을 검증용 데이터로 실행한다. 선택한 데이터만 지워지고 선택하지 않은 데이터와 원본 증빙 파일은 유지되는지 확인한다. 결제 초기화 시 연결은 해제된다. 실행 전 취소한 경우에는 아무것도 지워지지 않아야 한다.
- [ ] 실제 카드 Excel을 이미 미정 지출이 있는 상태, 이미 분류된 결제가 있는 상태에 각각 가져온다. 같은 날짜·금액·근접 시각이지만 상호명이 다른 카드/은행 거래에 Yes / No가 표시되는지, Yes는 중복 없이 병합하고 기존 분류를 보존하는지, No는 별도 거래를 유지하는지 확인한다.
- [ ] 같은 파일 재가져오기에서 중복이 늘지 않고, 은행에만 있는 거래는 누락되지 않는다. 복수 병합 후보가 있을 때 앱이 임의로 확정하지 않는다.

## 사용자가 별도로 진행할 검증

- [ ] 실제 승인·전체 취소·부분 취소 알림, 알림 접근 권한 취소 후 재허용.
- [ ] 홈 위젯 표시와 재부팅 후 유지.
- [ ] Play 배포 업데이트 이후 기존 데이터 유지.

MGC 원본 날짜 손상/OCR 오독의 추가 원인 검증은 취소했다. 테스트를 위해 앱 삭제가 필요하면 검증용 설치에서만 진행한다. 이번 디버그 업데이트는 versionCode를 증가시키지 않는다.
