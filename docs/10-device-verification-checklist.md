### 검증 중 발견한 안내 개선점

- 미정 지출 상단의 가져오기 요약은 가져온 직후의 집계다. Yes/No를 모두 처리해도 ‘중복 확인 필요 4건’이 남아 실제 남은 확인 건수처럼 보일 수 있었다. **1.3.6 / code 10에서 수정:** ‘가져오기 당시 집계 · 중복 후보’와 ‘현재 중복 확인 필요’를 분리했다. 현재 건수는 실제 미정 거래를 기준으로 Yes/No 직후 갱신하며, 복수 후보도 거래 한 건으로 집계한다. 단위·컴포넌트 및 앱 통합 회귀로 확인했다. 해당 안내 변경의 실기기 시각 검수는 이번 릴리스 생성 작업에서 추가로 실행하지 않았다.
- KFC 원본 사진의 하단 잘림은 앱 출력 과정의 손실이 아니다. 잘린 사진을 추가한 뒤 PDF에서 복원할 수는 없으므로 원본 전체가 들어오도록 재촬영하는 것이 필요하다.

- [x] 전체/미연결/날짜 확인 필터와 연결 완료 접기가 자연스럽고 `다음 미연결`이 해당 카드로 이동한다. 날짜를 그대로 두고 입력칸을 나와도 연결이 유지되며 실제로 날짜를 바꾸면 해제된다. 다시 분류한 결제의 최신 카테고리가 새 PDF에 반영된다.
- [x] 원본 증빙을 읽지 못하는 상태에서 해당 파일명·재첨부/삭제 안내가 보이고 생성이 차단된다. 재첨부 후 날짜·연결을 다시 확인하고 생성할 수 있다. 정상 파일은 지워지지 않는다.
- [x] 결제 검색(상호명·금액), 현재 기간/전체 기간, 세부 항목, 정렬·페이지를 변경한다. 상세 진입 후 뒤로 돌아왔을 때 목록 조건과 스크롤이 유지된다.
- [x] 작은 화면·OS 최대 글자·고대비에서 금액 입력·필터·복구 버튼에 접근할 수 있고 가로 넘침이 없다. PDF 도움말이 접힌 영수증의 실제 입력/후보를 가리키며 다음·이전·닫기가 자연스럽다.
- [x] 새 PDF에서 요약은 지원금 반영 금액이고 원본 은행 표·영수증의 실제 결제 금액은 변경되지 않는다. 기존 마스킹 경계·긴 영수증 한 장당 한 페이지·미연결 별도 묶음·5MB 제한·미리보기를 확인한다.

### 미체크 항목과 수정 후 재검증

- 지원금 금액의 핵심 흐름·최종 10,000원 PDF 반영 및 네이티브 위젯 저장값은 통과. 실제 홈 위젯 숫자 표시와 30,000원 상태의 별도 PDF는 이번에 확인하지 않았다.
- 큰 글자 미정 카드 날짜/금액 및 분류·제외 넘침과 고대비 다음 미연결 버튼 색상을 수정했다. OS 2.0 + 앱 크게 + 고대비에서 재검증 통과. 분류·제외는 같은 폭·높이로 표시된다.
- 도움말 버튼 단어 분할·확대 표시 영역 및 누락 삭제 버튼 외형을 보완하고 재검증했다. 도움말 6단계와 좁은 확대 화면의 내부 스크롤/버튼 접근성 통과. 네이티브 CANCEL/OK 문구는 이번에 변경하지 않았다.
- PDF 8페이지 전체 시각 검수: 373,893B, 사용 합계 52,000원(교통 10,000원/카페 42,000원), 원본 금액 보존, 최신 분류·미연결 별도 묶음 확인.
- 이번 재실행은 관련 회귀 75개/보안 112파일 통과. 실제 사진 정확도·20장 성능·압축 3종은 이번에 다시 검증하지 않았다.
