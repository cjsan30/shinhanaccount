# 최신 결정사항

## 기준 기기와 배포

- 1차 실제 검증 기기: Samsung Galaxy S25 Ultra / Android 16
- 초기 배포: 서명 APK를 4명에게 직접 배포
- 각 사용자의 데이터·정책·카드 끝 4자리는 독립적으로 기기 내 암호화 저장

## SMS와 분류

- 사용자는 앱 초기 설정에서 카드 끝 4자리와 개인정보를 가린 SMS 샘플을 직접 입력한다.
- 1차 승인 형식: `[신한체크승인] 사용자(3741) 07/24 17:58 (금액)8,000원 삼성웰스토리(주)크래프톤정`
- 추출값: 카드 끝 4자리, 거래 시각, 금액, 상호명
- 원문 SMS는 확인 후 저장하지 않으며 DB·로그·백업에 포함하지 않는다.
- 삼성웰스토리 8,000원은 정주비/식비, 그 외 삼성웰스토리는 학습공간 지원비/일반카페로 분류한다.
- 취소 SMS 샘플 확보 전에는 자동 차감을 활성화하지 않고 `취소 확인 필요`에 보관한다.

## 정책과 알림

- 정책 기간: 매월 10일 00:00부터 다음 달 9일 23:59:59까지 (한국 시간)
- 정책은 기본값으로 자동 생성하지 않는다. 사용자가 정책표를 입력·검토·확정한 뒤에만 예산을 사용한다. 정주비 500,000원·학습공간 지원비 200,000원은 정책 입력 시의 상한이다.
- 카테고리별 알림 기본값: 50%, 80%; 사용자가 슬라이더로 변경 가능
- 수동 분류로 임계치 도달 시에도 자동 분류와 동일하게 로컬 알림을 보낸다.

## 앱 식별값과 서명

- 표시 이름: `신청해 계산기`
- Android 패키지 ID: `io.github.cjsan30.shinhanhae.calculator`
- 앱 아이콘 원본: `assets/app-icon-calculator.png`
- 개발 중에는 Android debug key를 사용한다.
- 최초 공유 APK 직전에 별도의 release keystore를 생성한다.
- release keystore와 비밀번호는 비밀번호 관리자에 보관하고, 암호화된 별도 저장소에 백업 1개를 둔다.
- keystore·비밀번호·서명된 APK/AAB는 Git 저장소에 커밋하지 않는다.

## 내역 가져오기와 정책 입력

- 신한카드 앱의 `.xls`·`.xlsx` 이용내역을 앱에서 직접 선택해 가져온다.
- 첫 가져오기는 개발용 데모 거래를 실제 거래로 교체하고, 이후 가져오기는 승인번호로 중복을 제외한다.
- `승인`·`결제확정`이며 취소 상태가 비어 있는 행만 장부 후보로 처리한다.
- 출시용 빌드는 빈 장부로 시작하며, 개발용 미리보기에서만 데모 데이터를 사용한다.
- 정책표는 모바일 웹의 스크린샷 OCR 또는 표 텍스트 복사·붙여넣기로 초안을 만들 수 있다.
- OCR·붙여넣기 결과는 자동 확정하지 않는다. 사용자가 한도·카테고리별 계획 금액을 검토·수정한 뒤 `정책 확정`을 눌러야 적용한다.
- 신청해 웹사이트의 직접 로그인·세션 연동은 하지 않는다. 공식 API나 내보내기 파일이 제공될 때만 별도 연동을 검토한다.
- 정책 확정·예산 표시는 사용처가 아닌 지원 항목 7개(주거비, 식비, 교육비, 교통비, 스터디카페, 카페, 독서실)를 기준으로 한다. 사용처는 개인별 자유 입력 설명으로 취급한다.

## 카드 식별·파일 가져오기 안전 정책 (2026-08-05)

- 앱 첫 화면에서 SMS 수신·알림 권한을 모두 안내·요청한 뒤 정책 온보딩을 시작한다.
- 카드 끝 4자리는 사용자가 직접 입력한다. 기본 표시는 `••••`이며, 우측 마스킹 해제 버튼으로만 확인한다.
- 카드사 엑셀·은행 PDF의 마스킹 카드 식별값에서 설정 카드 끝 4자리의 앞 3자리와 같은 행만 가져온다. 다른 카드 행은 제외한다.
- 동일 앞 3자리의 서로 다른 실제 카드가 파일의 별도 카드 식별자로 식별되면 파일을 거절하고 `카드 하나만 선택해 결제 내역을 다시 받아 주세요.`를 표시한다.
- 마스킹 값만으로 서로 다른 실제 카드를 구분할 수 없으면 카드사 앱에서 카드 하나를 선택해 파일을 받는 것이 사용자 책임임을 미리보기에서 안내한다.
- 가져온 거래에는 사용자가 설정한 카드 끝 4자리를 내부 연결한다. 이는 이후 취소 SMS 매칭에 사용하며 화면에는 기본 마스킹한다.
