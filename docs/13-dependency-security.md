# 의존성 보안 기준

## SheetJS 엑셀 가져오기

신한카드 이용내역은 `.xls`와 `.xlsx` 형식으로 제공될 수 있으므로, 앱은 두 형식을 모두 읽어야 한다.

- 기존 상태: npm 레지스트리의 `xlsx@0.18.5`
- 문제: Prototype Pollution(CVE-2023-30533)과 ReDoS(CVE-2024-22363)에 영향을 받는다.
- 조치: SheetJS 공식 CDN의 수정 버전 `xlsx@0.20.3`을 프로젝트 내부 `app/vendor/xlsx-0.20.3.tgz`에 고정한다.
- SHA-256: `8DC73FC3B00203E72D176E85B50938627C7B086E607C682E8D3C22C02BB99FE8`

로컬 vendor 방식은 빌드 때 외부 CDN에 의존하지 않고, 잠금 파일과 함께 같은 파서 버전을 재현한다. 새 버전으로 갱신할 때는 공식 배포 파일의 버전·SHA-256·`npm audit --omit=dev` 결과를 함께 확인한다.

## 파일 입력 방어

- 사용자 선택으로만 파일을 읽고, 허용 확장자는 `.xls`와 `.xlsx`로 제한한다.
- 읽은 값은 신한카드 거래 내역의 필요한 열만 추출하며, 원본 파일이나 거래 내용은 서버로 전송하지 않는다.
- 파일 파싱 실패·형식 불일치는 가져오기 실패로 처리하고 거래 데이터에 반영하지 않는다.
