# Play 업데이트 준비 — 1.3.2

| 항목 | 값 |
| --- | --- |
| 트랙 | 현재 사용 중인 비공개 테스트 트랙 |

## Play Console 변경사항

```text
• 미정 지출을 여러 건 선택해 하단 고정 영역에서 빠르게 분류할 수 있도록 개선했습니다.
• 분류 후 선택 상태가 남아 다음 분류를 방해하던 문제를 수정했습니다.
• 홈 화면 가로 위젯의 금액과 항목 표시를 더 읽기 쉽게 조정했습니다.
```

## 업로드 전 확인

- [ ] `build-play-release.ps1` 완료 후 AAB와 APK가 모두 생성되었는지 확인
- [ ] 빌드 출력의 `AAB SHA-256` 기록
- [ ] Play Console에서 버전 코드 `6`이 표시되는지 확인
- [ ] 비공개 테스트 트랙에 변경사항을 저장하고 검토·출시
- [ ] Play 스토어에서 기존 테스트 빌드 위로 업데이트 설치되는지 확인

## 참고

- Play Console에는 서명된 **AAB만** 업로드한다. APK는 직접 설치·실기기 검증용이다.
- 이번 변경은 권한·Data safety 답변을 바꾸지 않는다. 알림 접근만 사용하며 `READ_SMS`와 `RECEIVE_SMS`는 릴리스 매니페스트에 포함되지 않아야 한다.
