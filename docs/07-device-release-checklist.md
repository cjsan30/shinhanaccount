# 실기기 최종 검증 체크리스트

## 목적

기능 변경을 모두 묶은 최종 APK에서 Galaxy S25 Ultra / Android 16 기준으로 한 번에 검증한다. 개별 수정 중에는 부분 실기기 검증을 반복하지 않는다.

## 사전 준비

- [ ] release keystore로 서명한 APK와 버전 정보를 준비한다.
- [ ] 기존 앱 데이터가 남아 있지 않은 테스트 환경 또는 앱 데이터 초기화 환경을 준비한다.
- [ ] 카드 끝 4자리, 개인정보를 가린 승인 SMS, 취소 SMS 샘플을 준비한다.
- [ ] 신한카드 단일 카드 `.xls` 또는 `.xlsx` 파일을 준비한다.
- [ ] 정주비·학습공간비 증빙 이미지 여러 장을 준비한다.

## 신규 사용자 흐름

- [ ] 앱 설치 후 SMS·알림 권한 안내와 요청이 온보딩 전에 표시된다.
- [ ] 카드 끝 4자리와 정책을 확정하기 전에는 대시보드에 진입할 수 없다.
- [ ] 정책 이미지 OCR 결과를 검토·수정하고 정책을 확정할 수 있다.
- [ ] 정책 확정 직후 사용액은 0원이며, 총 잔액·정주비·학습공간비가 정책값과 일치한다.

## 거래와 알림

- [ ] 실제 승인 SMS가 카드 끝 4자리와 일치할 때만 반영된다.
- [ ] 규칙 없는 상호명은 미정으로 저장되고 총 사용액에는 포함되지 않는다.
- [ ] 수동 분류 시 예산과 임계치 알림이 갱신된다.
- [ ] 50%·80% 또는 사용자가 변경한 임계치에서 앱 내·상단바·알림음이 모두 동작한다.
- [ ] 실제 취소 SMS 샘플 확보 후 자동 매칭과 `취소 확인 필요`를 별도 검증한다.

## 파일·백업·증빙

- [ ] 카드 엑셀 가져오기는 설정 카드 앞 3자리와 일치하는 행만 후보로 표시한다.
- [ ] 앞 3자리가 같은 서로 다른 카드가 감지되면 `카드 하나만 선택해 결제 내역을 다시 받아 주세요.`가 표시된다.
- [ ] 암호화 백업은 Android Documents 폴더에 저장되고 새 설치 환경에서 복원된다.
- [ ] 증빙 이미지를 정주비와 학습공간비로 나누어 추가하고 순서를 바꿀 수 있다.
- [ ] 생성한 증빙 PDF는 5MB 이하이며 Documents 폴더에서 열리고 제출 자료가 모두 읽힌다.

## 위젯

- [ ] 금액 표시형 위젯의 총 잔액·미정 건수가 앱과 일치한다.
- [ ] 금액 숨김형 위젯은 금액을 노출하지 않는다.
- [ ] SMS·수동 등록·분류 변경·취소·정책 변경·복원 후 위젯이 갱신된다.

## 통과 기준

- P0 항목이 모두 통과하고, 개인정보·원문 SMS·카드 전체 번호가 저장 파일이나 화면에 노출되지 않는다.
- 실패 항목은 재현 절차, 앱 버전, 화면 캡처만 기록하고 민감한 원문은 공유하지 않는다.
