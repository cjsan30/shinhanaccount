# Google Play 공개 배포 개인정보 고지 초안

## 1. 자동 결제 인식 범위

신청해 계산기는 사용자가 Android 시스템 설정에서 직접 허용한 **알림 접근 권한**을 사용한다. 자동 인식 대상은 삼성 메시지 앱(`com.samsung.android.messaging`), 신한 SOL(`com.shinhan.sbanking`), 신한카드 앱(`com.shinhancard.smartshinhan`)에 게시된 알림 중 다음 조건을 모두 만족하는 항목뿐이다.

- 신한카드 승인 형식과 일치한다.
- 사용자가 앱에 등록한 카드 끝 4자리와 일치한다.
- 결제 시각, 금액, 상호명을 정상적으로 확인할 수 있다.

허용 대상 외 다른 앱의 알림과 신한카드 승인 형식이 아닌 알림은 거래로 처리하지 않는다. 두 허용 앱에서 같은 카드·승인 시각·금액·상호명으로 90초 안에 도착한 알림은 한 거래로 합치며, 그 짝은 이후 중복 판단에 다시 사용하지 않는다.

## 2. 저장하는 정보

- 결제 시각과 알림 게시 시각
- 결제 금액
- 상호명
- 카드 끝 4자리
- 사용자가 정한 분류, 상태, 자동 분류 규칙
- 같은 알림의 중복 처리를 막기 위한 비가역 출처 식별값

위 정보는 기기 안의 암호화 SQLite와 Android Keystore 기반 암호화 설정 저장소에 저장한다. 서버, Notion 또는 제3자 분석 서비스로 전송하지 않는다.

## 3. 저장하거나 처리하지 않는 정보

- SMS·MMS·통화 기록
- 카드 전체 번호
- 승인 알림 원문과 발신자 정보
- 다른 앱의 알림 내용
- 삼성 메시지의 일반 대화 내용

앱은 `READ_SMS`와 `RECEIVE_SMS` 권한을 요청하지 않는다. 처리한 삼성 메시지 알림을 상단바에서 삭제하지 않는다.

## 4. 권한과 거부 시 동작

- **알림 접근:** 삼성 메시지·신한 SOL·신한카드 앱의 승인 알림을 자동 인식하는 데 사용한다. 사용자는 Android 시스템 설정에서 언제든 해제할 수 있다.
- **앱 알림:** 결제 인식 결과와 예산 경고를 표시하는 데 사용한다.

알림 접근을 허용하지 않거나 중단해도 신한카드 엑셀 가져오기와 직접 지출 등록은 사용할 수 있다. 접근 중단 기간의 거래는 자동 복구되지 않을 수 있으므로 파일 가져오기로 대조한다.

## 5. 보관·삭제·이동

- 사용자는 앱에서 개별 결제를 수정·취소·삭제할 수 있다.
- 앱 데이터 초기화 또는 앱 삭제 시 기기 내부 데이터가 삭제된다.
- 암호화 백업은 사용자가 명시적으로 실행할 때만 기기 다운로드 폴더에 생성된다.
- 백업 파일의 보관과 삭제는 사용자가 관리한다.

## 6. Play Console 준비 항목

- 개인정보처리방침 공개 URL: **배포 전 입력 필요**
- 개인정보 문의 연락처: **배포 전 입력 필요**
- Data safety: 금융 관련 앱 활동 데이터가 기기 밖으로 수집·공유되지 않는 현재 구조를 실제 릴리스 빌드와 대조해 작성
- 스토어 설명: `승인 알림 접근 필요`, `신한카드 승인 알림 자동 인식`, `엑셀·수동 입력 대체 경로`를 명시
- 심사 자료: 최초 온보딩의 주요 고지 화면과 알림 접근 설정 절차를 캡처

## 7. 릴리스 차단 조건

다음 중 하나라도 해당하면 공개 제출을 중단한다.

- 병합 매니페스트에 `READ_SMS` 또는 `RECEIVE_SMS`가 포함됨
- 원문 알림이 DB·로그·백업·오류 보고에 남음
- 고지 전에 알림 접근 설정 화면을 엶
- 알림 접근을 거부하면 앱 전체 사용이 불가능하고 엑셀·수동 등록 대체 경로도 없음
- 개인정보처리방침 URL 또는 문의 연락처가 준비되지 않음
