# 제출서류·거래내역 실기기 피드백 정리

작성일: 2026-10-01

## 실기기 검증 결과 요약

- 자동 확인 6개 항목은 통과했다: 암호화 저장소, 정책 상태, 거래 계산 무결성, 가져오기 반영, 분류 반영, 증빙 준비.
- 사용자 확정에서는 실제 결제 알림, 백업·복원, 제출서류 품질, 홈 위젯, Play 업데이트 데이터 유지는 통과했다.
- `가져오기 정확성`은 실패로 남았다. 은행 PDF 표의 열 값이 일부 합쳐지고, 제출용 표에 기간 외·입금 행이 포함되는 문제를 수정한 뒤 재검증한다.
- `온보딩 선택 보존`은 이번 회차에 미확정이다.

## 확정된 수정 사항

### 거래내역 등록 안내·용량

- 카드 전용 자동재생 영상과 포스터는 제거한다. 카드·은행 파일을 함께 다루는 화면에서는 영상보다 선택한 파일 유형에 맞춘 짧은 안내가 혼동을 줄인다.
- 카드번호 선택 시 `신한카드 앱 → 카드이용내역 → CSV 저장`과 CSV·Excel 지원, 정책 기간 내 승인 내역만 가져오는 점을 안내한다.
- 계좌번호 선택 시 `신한은행 입출금내역 PDF`, 보호된 PDF 비밀번호, 기간 내 출금만 후보로 가져오는 점을 안내한다.
- 카드 가이드 영상·포스터 제거로 앱 번들에서 약 1.7MB를 절감한다.

### 미정 지출·데이터 초기화

- `바로 분류`와 `사업 무관 제외` 버튼은 동일한 폭·높이·행 위치를 사용하고 색상만 구분한다.
- 데이터 초기화 범위는 체크박스와 설명이 한 덩어리로 보이는 선택 카드 UI로 바꾼다.

### 입출금내역

- 제출서류에는 입금 행을 넣지 않는다.
- 제출용 표는 `일자 / 출금 / 내용 / 잔액`만 표시한다. 내용 열을 가장 넓게 배정한다.
- 정책 기간 밖 거래는 거래내역 가져오기와 제출서류 양쪽에서 제외한다.
- 사용 기간은 현재 매월 15일~다음 달 10일을 기본 규칙으로 적용한다. 사업별 예외 기간을 직접 입력하는 기능은 모든 예산·알림·위젯 계산에 같은 기간을 적용하도록 별도 확장한다.
- 신한은행 PDF도 실제 표 구조에 맞춰 파싱을 보정한다. 신한카드 CSV·Excel은 별도 실제 파일로 회귀 검증한다.
- 보호된 PDF를 다시 읽는 행동은 충분한 대비색을 사용한다.
- 긴 파일명은 앞부분과 확장자를 남기는 중간 생략 표기로 표시한다.

### 영수증·제출서류

- 세로로 긴 영수증도 한 이미지가 PDF 한 페이지에만 들어가도록 비율 유지 축소한다. PDF 페이지로 분할하지 않는다.
- PDF 결과 열기는 Android WebView 안쪽 `<object>` 미리보기에 의존하지 않는다. `미리보기` 버튼은 기기의 외부 PDF 앱으로 파일을 연다.
- 영수증 금액·결제처 입력값은 입력 중 매번 암호화 저장소에 쓰지 않고, 입력칸 이탈 시 저장한다.

## 영수증 연결: 목표 동작

1. 영수증 OCR로 날짜·금액·결제처 후보를 추출한다.
2. 날짜와 금액이 일치하는 결제가 정확히 하나이면 자동 연결한다. 결제처 유사는 신뢰도를 높이는 보조 근거다.
3. 같은 금액 결제가 여러 건이거나 OCR 값이 없거나 불명확하면 자동 연결하지 않는다.
4. 이 경우에만 추천 후보와 직접 선택을 보여 주고, 사용자가 연결한다.
5. 추천 후보는 직접 선택보다 위에 크게 표시하고, 직접 선택은 보조 수단으로 둔다.

## 압축·알고리즘 검증 규칙

- 품질 비교: 짧은·일반·긴 영수증 최소 3장으로 `default / compact / minimum` PDF 3개를 생성한다. 이 검증은 선명도와 잘림을 비교하는 목적이다.
- 알고리즘 시간: 실제 제출 규모의 영수증 20장 이상을 동일한 순서로 넣고 과거 방식은 기준값으로 1회, 현재 방식은 변동을 줄이기 위해 3회 측정한다. 현재 방식의 중앙값·파일 크기·처리 횟수를 기록한다.
- 최종 PDF 생성: 입출금내역, 거래증빙, 영수증 연결이 모두 끝난 입력으로 1회 실행한다. 이는 품질 비교·성능 측정과 별도의 최종 통합 검증이다.

## 구현 기준

- 정책 기간 기본값은 매월 15일~다음 달 10일이며, 11~14일은 어느 기간에도 포함하지 않는다. 예외 기간의 사용자 입력 UI는 별도 기능으로 확장한다.
- 한국어 온디바이스 OCR은 이미 계획표 인식에 탑재한 ML Kit을 재사용한다. 영수증 OCR을 추가해도 별도 OCR 엔진을 새로 넣지 않는다.
- 자동 연결은 `날짜+금액`이 정확히 하나인 경우에만 수행한다. 동률·OCR 불확실·필수값 누락은 추천 후보와 직접 선택으로 남긴다.
