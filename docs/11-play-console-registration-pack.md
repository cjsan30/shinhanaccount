# Google Play Console 등록 패키지

기준일: 2026-08-21  
대상 빌드: `신청해 계산기 1.3.2` (`versionCode 6`)

이 문서는 개발자 계정 승인 후 Play Console에 앱을 생성·내부 테스트 등록하기 위해 필요한 입력값과 산출물을 한 곳에 모은 것이다. 앱 생성·출시 자체는 이 문서로 자동 실행하지 않는다.

## 1. 앱 생성 입력값

| Play Console 항목 | 입력값 |
| --- | --- |
| 기본 언어 | 한국어(대한민국) |
| 앱 이름 | 신청해 계산기 |
| 앱 또는 게임 | 앱 |
| 무료 또는 유료 | 무료 |
| 지원 이메일 | **사용자 확정 필요** |
| 앱 패키지 ID | `io.github.cjsan30.shinhanhae.calculator` |
| 개발자 프로그램 정책 | 동의 |
| 미국 수출법 | 동의 |
| Play App Signing | 사용 및 약관 동의 |

지원 이메일은 Play 스토어에 공개된다. 개인 주소 대신 이 앱 전용 Gmail 별칭을 권장한다. 계정·로그인 기능은 없으므로 계정 삭제 URL은 필요하지 않다.

### 짧은 설명

`신청해 지원금의 계획, 결제 내역, 잔액과 증빙을 한곳에서 관리합니다`

### 전체 설명

```text
신청해 계산기는 지원금 사용 계획과 실제 지출을 기기 안에서 관리하는 Android 앱입니다.

주요 기능
• 정주비와 학습공간비의 계획 금액, 사용액, 잔액 확인
• 삼성 메시지·신한 SOL의 신한카드 승인 알림 자동 인식
• 처음 보는 결제처는 미정 지출로 보관한 뒤 직접 분류
• 상호명 키워드 기반 자동 분류 규칙
• 예산 사용률 1차·2차 경고와 초과 알림
• 신한카드 엑셀 거래내역 가져오기
• 직접 지출 등록과 결제 내역 수정·취소·삭제
• 홈 화면 위젯에서 잔액과 사용률 확인
• 영수증 이미지를 순서대로 합친 증빙 PDF 생성
• 암호화 백업과 복원

개인정보와 데이터
자동 인식은 사용자가 허용한 삼성 메시지·신한 SOL 알림 중 등록한 카드와 일치하는 신한카드 승인 알림만 기기 안에서 처리합니다. 같은 승인이 두 앱에 표시되면 한 건으로 합칩니다. 원문 알림과 다른 대화는 저장하거나 외부로 전송하지 않습니다. 거래·정책·분류 규칙은 기기 내부 암호화 저장소에 보관합니다. 알림 접근을 사용하지 않는 경우에도 신한카드 엑셀 가져오기와 직접 등록을 사용할 수 있습니다.
```

## 5. Data safety 답변 초안

현재 릴리스 코드는 거래·정책·규칙·진단 메타데이터를 기기 안에서만 처리하고 서버나 제3자에게 전송하지 않는다.

| 질문 | 답변 |
| --- | --- |
| 앱이 사용자 데이터를 수집하거나 공유합니까? | 아니요 |
| 데이터 전송 중 암호화 | 해당 없음 — 외부 전송 없음 |
| 계정 생성 | 없음 |
| 데이터 삭제 요청 | 계정 없음. 사용자는 앱에서 결제를 삭제하거나 Android 앱 데이터 삭제·앱 제거로 기기 데이터를 삭제할 수 있음. |
| 민감 권한 | `READ_SMS`, `RECEIVE_SMS` 미사용. 사용자가 Android 설정에서 허용한 알림 접근만 사용. |

Data safety는 내부 테스트 전용 트랙만 사용할 경우 스토어 표시 면제 대상일 수 있어도, 공개·비공개·프로덕션 테스트 또는 출시 전에는 반드시 작성한다. AAB 업로드 후 Console이 표시하는 SDK·권한 경고와 이 표가 일치하는지 다시 대조한다.

## 6. 릴리스 산출물

| 용도 | 파일 |
| --- | --- |
| Play Console 업로드 | `app/android/app/build/outputs/bundle/release/app-release.aab` |
| 직접 설치·실기기 검증 | `app/android/app/build/outputs/apk/release/app-release.apk` |

현재 AAB/APK는 동일한 릴리스 키로 서명된 1.3.2 빌드다. Play Console에는 AAB만 업로드하고 APK는 업로드하지 않는다.

### 내부 테스트 릴리스 노트

```text
1.3.2
• 미정 지출을 여러 건 선택해 빠르게 분류할 수 있습니다.
• 분류 후 선택 상태가 남는 문제를 수정했습니다.
• 홈 화면 위젯의 금액과 항목 가독성을 개선했습니다.
```

## 7. 승인 직후 실행 순서

1. Play Console에서 위 1번 값으로 앱을 생성한다.
2. 개인정보처리방침 URL, 지원 이메일, 스토어 설명·그래픽을 등록한다.
3. 앱 콘텐츠, 콘텐츠 등급, Data safety를 위 초안으로 작성한다.
4. 내부 테스트 트랙에 AAB를 업로드하고 내부 테스터 목록을 추가한다.
5. 실제 기기에서 설치·온보딩·직접 지출·알림 접근·위젯을 확인한다.
6. 개인 개발자 계정의 프로덕션 테스트 요건이 적용되는 경우, 비공개 테스트 12명 이상·14일 요건을 충족한 뒤 프로덕션 액세스를 신청한다.

## 8. 출시 전 차단 점검

- [ ] 지원 이메일 확정
- [ ] 개인정보처리방침 URL 브라우저에서 HTTP 200 확인

- [ ] Console의 앱 번들 탐색기에서 `READ_SMS`·`RECEIVE_SMS` 부재 확인
- [ ] Data safety 답변과 앱 내부 고지·개인정보처리방침 일치 확인
- [ ] 스크린샷에서 개인정보·상단 알림·통신사 정보 제거 확인
- [ ] 내부 테스트 설치·업데이트·알림 접근 실기기 검증 완료
