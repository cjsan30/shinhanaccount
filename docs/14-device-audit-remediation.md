- 대분류 상세와 데이터 관리의 계획표에 예산 조정 폼을 제공한다. 저장 중 중복 실행을 차단하고, 실패 시 성공 안내 없이 입력을 유지해 재시도한다. 실제 지출·분류·첨부 연결·예약 계획·기간·경고 대상은 변경하지 않는다.
