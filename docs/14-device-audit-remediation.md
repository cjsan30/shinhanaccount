## 완료 범위와 평가 기준

마지막 반응형 점검에서 발견한 추가 문제도 수정했다. 320px 화면에 OS 글자 2배·앱 큰 글자·고대비를 함께 적용하면 빠른 확인 메뉴와 창 제목이 밀리던 문제를 줄바꿈·최소 너비로 해결했다. 확대 설정에서 모달 너비가 확대 배율만큼 넘치던 문제도 보정했다. PDF 도움말은 실제 보이는 화면 높이에 맞춰 설명 카드 위치를 제한해 6단계 모두 화면 안에 유지했다.

기간 계산 일관성을 점검하면서 앱의 요약·항목별 사용액·위젯 집계도 부분 취소 후 남은 결제금액을 사용하도록 맞췄다. 실제 부분 취소 알림의 수신과 반영은 사용자의 별도 실기기 검증으로 남긴다.

## 자동 검증 결과

- 웹 단위·컴포넌트·통합 회귀: 47개 파일, 265개 테스트 통과. 초기화 테스트는 비어 있지 않은 정책·분류 규칙으로 8가지 조합(선택 없음 포함)을 재확인했다.
- Android 단위: 27개 통과.
- Android 기기 통합: 에뮬레이터 3개, Galaxy S25 Ultra / Android 16 실기기 3개 통과. 앱 패키지·알림 리스너/위젯 등록·암호화 설정 저장/조회 검증이며 실제 결제 알림이나 위젯 표시의 대체 검증은 아니다.
- 소스 보안 검사: 웹·네이티브 107개 파일 통과. 기존 암호화·백업·입력 검증 테스트도 전체 회귀에 포함된다. 외부 침투 테스트/보안 인증을 의미하지 않는다.
- lint, TypeScript 내부 빌드, Android debug/test APK 빌드 통과.
- 에뮬레이터 반응형 점검: 실제 보이는 폭 320px, OS 글자 배율 2.0, 앱 큰 글자/고대비 조합에서 대시보드·계획 검토·PDF 생성과 도움말의 가로 넘침 및 설명 카드 위치 확인. 수정 후 PDF 도움말 6단계 모두 화면 안에 표시됨.

## 실기기 설치

- 기존 설치본과 debug key 서명이 달라 `install -r`은 거부됐다. 사용자가 허용한 삭제/재설치 방식으로 최신 디버그를 설치했다.
- **기존 앱 내부 데이터는 삭제됐다.** 이 실행에서 삭제 전 백업은 생성하지 않았다. 기존에 외부 Downloads에 저장한 PDF·백업 파일은 앱 삭제 대상이 아니다.
- 설치 성공과 DEBUGGABLE, versionName 1.3.5 / versionCode 9를 확인했다. WebView의 최신 번들 `index-C7GOwkjy.js`도 확인했다.
- APK: `app/android/app/build/outputs/apk/debug/app-debug.apk`, 81,183,610바이트. debug 범용 APK이며 Play 배포 파일이 아니다.
- 앱은 초기 지원자 선택 화면으로 실행해 두었다. 실제 알림·위젯·Play 업데이트 유지 검증은 수행했다고 간주하지 않는다.

## 다음 실기기 검증

전체 실행 순서·조건은 [실기기 확인 체크리스트](10-device-verification-checklist.md)에 있다.

1. UI: 고대비/최대 글자, 미정 지출 간격, 수동 날짜 안내, PDF 도움말.
2. 정책: 기간 편집·확정·재시작과 예산/가져오기/PDF의 동일 경계 확인.
3. PDF/측정: 3가지 품질 파일의 모든 페이지 확대 검수, 20장 이상 동일 입력 시간 비교와 취소 확인.
4. 데이터: 초기화 선택 7가지 조합과 취소, 실제 카드 Excel의 미정/확정 거래 병합·분류 보존·재가져오기 중복 확인.
5. 사용자 담당: 실제 승인·전체/부분 취소·권한 재허용, 위젯·재부팅, Play 업데이트 데이터 유지.

MGC 날짜 차이의 추가 원인 검증은 요청대로 취소했다. OCR 인식 정확도 개선을 완료했다고 보고하지 않는다.
