# 신청해 지원금 관리 — Notion 템플릿 설계서

> 문서 인코딩: UTF-8 with BOM / Windows CRLF  
> 기준 자료: `신청해_템플릿용.pdf`  
> 적용 대상: 정주비 50만원 + 학습공간 지원비 20만원 = 총 700,000원

# 1. 지원금 기본 조건

## 1.1 사용자 적용 조건

| 구분 | 한도 |
|---|---:|
| 정주비 | 500,000원 |
| 학습공간 지원비 | 200,000원 |
| 총 지원금 | 700,000원 |

정주비와 학습공간 지원비는 통합 지급되지만, 사용처와 개별 한도는 분리해서 관리한다.

검증 규칙:

1. 정주비 사용액은 500,000원을 초과할 수 없다.
2. 학습공간 지원비 사용액은 200,000원을 초과할 수 없다.
3. 전체 사용액은 700,000원을 초과할 수 없다.
4. 정주비 내 각 항목은 별도 항목별 한도를 준수해야 한다.

## 1.2 정주비 항목별 한도

| 항목 | 최대 금액 |
|---|---:|
| 주거비 | 500,000원 |
| 교통비 | 400,000원 |
| 교육비 | 400,000원 |
| 식비 | 200,000원 |

정주비 항목별 한도의 합계는 정주비 총 한도보다 크므로, 항목별 한도와 정주비 전체 한도를 동시에 검증한다.

예:

- 식비 200,000원 + 교육비 300,000원 = 정주비 500,000원: 가능
- 식비 200,000원 + 교육비 400,000원 = 정주비 600,000원: 정주비 총 한도 초과
- 교통비 410,000원: 교통비 항목 한도 초과

## 1.3 학습공간 지원비 한도

| 항목 | 최대 금액 |
|---|---:|
| 스터디카페 | 학습공간 지원비 총 200,000원 범위 |
| 독서실 | 학습공간 지원비 총 200,000원 범위 |
| 일반 카페 | 학습공간 지원비 총 200,000원 범위 |
| 공유오피스 | 학습공간 지원비 총 200,000원 범위 |

학습공간 지원비는 여러 사용처를 합산하여 총 200,000원까지 사용할 수 있다.

# 6. 데이터베이스 A — 지원금 설정

데이터베이스 이름: `지원금 설정`

한 행만 사용한다.

| 속성명 | 타입 | 기본값 |
|---|---|---|
| 지원사업명 | Title | 신청해 지원금 |
| 정주비한도 | Number | 500000 |
| 학습공간한도 | Number | 200000 |
| 총지원한도 | Formula | 700000 |
| 지출내역 | Relation | 지출결의서 |
| 정주비사용액 | Rollup | 지출결의서의 정주비반영액 Sum |
| 학습공간사용액 | Rollup | 지출결의서의 학습공간반영액 Sum |
| 총사용액 | Rollup | 지출결의서의 결제금액 Sum |
| 정주비잔액 | Formula | 정주비한도 - 정주비사용액 |
| 학습공간잔액 | Formula | 학습공간한도 - 학습공간사용액 |
| 총잔액 | Formula | 총지원한도 - 총사용액 |
| 정주비사용률 | Formula | 백분율 |
| 학습공간사용률 | Formula | 백분율 |
| 총사용률 | Formula | 백분율 |
| 정주비상태 | Formula | 정상 또는 초과 |
| 학습공간상태 | Formula | 정상 또는 초과 |
| 전체상태 | Formula | 정상 또는 초과 |

### 총지원한도

```notion
prop("정주비한도") + prop("학습공간한도")
```

### 잔액

```notion
prop("정주비한도") - prop("정주비사용액")
```

```notion
prop("학습공간한도") - prop("학습공간사용액")
```

```notion
prop("총지원한도") - prop("총사용액")
```

### 사용률

```notion
if(prop("정주비한도") == 0, 0, prop("정주비사용액") / prop("정주비한도"))
```

```notion
if(prop("학습공간한도") == 0, 0, prop("학습공간사용액") / prop("학습공간한도"))
```

```notion
if(prop("총지원한도") == 0, 0, prop("총사용액") / prop("총지원한도"))
```

### 상태

```notion
if(prop("정주비사용액") > prop("정주비한도"), "정주비 초과", "정상")
```

```notion
if(prop("학습공간사용액") > prop("학습공간한도"), "학습공간 초과", "정상")
```

```notion
if(prop("총사용액") > prop("총지원한도"), "총 한도 초과", "정상")
```

### 정주비반영액

```notion
if(prop("지원구분") == "정주비", prop("결제금액"), 0)
```

### 학습공간반영액

```notion
if(prop("지원구분") == "학습공간 지원비", prop("결제금액"), 0)
```

### 항목한도

```notion
ifs(
  prop("분류") == "주거비", 500000,
  prop("분류") == "교통비", 400000,
  prop("분류") == "교육비", 400000,
  prop("분류") == "식비", 200000,
  contains("스터디카페,독서실,일반카페,공유오피스", prop("분류")), 200000,
  0
)
```

### 지원구분검사

```notion
if(
  or(
    and(
      prop("지원구분") == "정주비",
      contains("주거비,교통비,교육비,식비", prop("분류"))
    ),
    and(
      prop("지원구분") == "학습공간 지원비",
      contains("스터디카페,독서실,일반카페,공유오피스", prop("분류"))
    )
  ),
  "일치",
  "지원구분 확인"
)
```

### 증빙요건

```notion
ifs(
  prop("분류") == "주거비", "계약서·고지서 + 이체확인증",
  prop("분류") == "교통비", "영수증·청구내역 + 이용 또는 승차 증빙",
  prop("분류") == "교육비", "상세 거래내역 영수증",
  prop("분류") == "식비", "상세 거래내역 영수증",
  contains("스터디카페,독서실,일반카페,공유오피스", prop("분류")), "상세 거래내역 영수증",
  "확인 필요"
)
```

### 영수증상태

```notion
if(empty(prop("영수증")), "영수증 누락", "첨부 완료")
```

### 추가증빙상태

```notion
ifs(
  prop("분류") == "주거비",
    if(empty(prop("추가증빙")), "추가증빙 누락", "첨부 완료"),
  prop("분류") == "교통비",
    if(empty(prop("추가증빙")), "추가증빙 누락", "첨부 완료"),
  "해당 없음"
)
```

### 필수정보상태

```notion
if(
  or(
    empty(prop("결제일")),
    empty(prop("지원구분")),
    empty(prop("분류")),
    empty(prop("상호명")),
    empty(prop("품목·서비스")),
    prop("결제금액") <= 0,
    empty(prop("사용목적"))
  ),
  "정보 누락",
  "입력 완료"
)
```

### 제출가능상태

```notion
if(
  and(
    prop("영수증상태") == "첨부 완료",
    prop("필수정보상태") == "입력 완료",
    prop("지원구분검사") == "일치",
    or(
      prop("추가증빙상태") == "첨부 완료",
      prop("추가증빙상태") == "해당 없음"
    ),
    prop("승인상태") != "반려"
  ),
  "제출 가능",
  "확인 필요"
)
```
